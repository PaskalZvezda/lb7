# bayan

Утилита для поиска файлов-дубликатов.

```
bayan [параметры] <директория>...
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `-d, --dir` | директории для сканирования (можно несколько) | |
| `-e, --exclude` | директории, исключаемые из сканирования (можно несколько) | |
| `-l, --level` | уровень сканирования, 0 - только указанная директория | 0 |
| `-m, --min-size` | минимальный размер файла в байтах | 1 |
| `-M, --mask` | маски имён файлов (`*`, `?`), регистр не учитывается | все файлы |
| `-b, --block-size` | размер блока S для чтения файлов | 1024 |
| `-H, --hash` | алгоритм хэширования H: `crc32` или `md5` | crc32 |
| `-h, --help` | справка | |

Пример:

```
bayan /home/user/docs /home/user/photos -l 2 -e /home/user/docs/tmp -M "*.txt" "*.jpg" -b 512 -H md5
```

Файлы с одинаковым содержимым выводятся группами, по одному полному пути на строке, группы разделяются пустой строкой.

Установка:

```
sudo apt install ./bayan-1.0.0-Linux.deb
```
